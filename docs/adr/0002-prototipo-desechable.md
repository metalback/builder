# El Prototipo es desechable; Desarrollo nunca hereda su código

El Prototipo del design sprint es HTML clicable que Desarrollo usa solo como referencia visual. La Idea se reconstruye desde cero con TDD. Lo descartamos como semilla de producción porque aplicar TDD sobre código no testeado obliga a trabajar al revés, y porque iterar en el Ciclo de reflexión sale barato justamente porque el Prototipo no carga las restricciones del código de producción. QA compara screenshots contra el Prototipo aprobado para detectar divergencias.
